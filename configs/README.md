# Configuration snapshots

`observed_2026-10-08/mid360_real_ros2.yaml` preserves the deployed SUPER configuration inspected during ground integration. It includes a 5 m/s planning limit and is not the final 2 m/s demonstration profile.

The separate ground diagnostic configuration is generated by `scripts/maintenance/create_super_ground_diagnostic.py`. Confirm actual running parameters using the [flight runbook](../docs/FIRST_HOVER_2026-10-09.md); an archived YAML does not establish its current runtime state.

`create_super_motion_profiles.py` creates separate 0.3 m/s / 0.5 m/s² baseline ground-preview, 0.3 m/s / 0.45 m/s² reserved-acceleration preview, 0.25 m/s / 0.45 m/s² reserved velocity/acceleration preview, and 2 m/s / 1 m/s² demonstration candidates from the current diagnostic YAML. It preserves all other configuration and refuses conflicting existing candidates. These are planner motion settings, not flight-ready profiles; see the [session workflow](../docs/SESSION_STARTUP.md#low-speed-preview-and-demonstration-candidate).

`rviz/super_ground_ros2.rviz` provides a ROS 2 ground planning view with registered clouds, occupied map, trajectories, path, and goal markers. It uses the raw `world`/`camera_init` alias and does not overlay aligned FC targets or publish goals. See the [live-view instructions](../docs/SESSION_STARTUP.md#live-rviz2-view).
