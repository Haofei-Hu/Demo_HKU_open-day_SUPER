## 悬停配置与启动顺序

地面飞控中心高度约 8.5 cm，用户要求的离地 1 m 指飞控中心。因此冻结当前地面本地 Z 后，目标是 `z_ground + 0.915 m`，固定起飞 XY 和 yaw。

```bash
source /opt/ros/humble/setup.zsh
python3 ~/Downloads/first_hover_terminal.py --execute --hover-height 1.0 --hold-seconds 6.0
```

启动日志应有 `hover FC=1 m, hold=6 s`，然后完成检查，出现 `Phase: READY`。`--execute` 和 READY 都不会自动切模式或解锁。只有操作者发起下面的服务后才启动一次任务：

```bash
ros2 service call /first_hover/start std_srvs/srv/Trigger '{}'
```

| 阶段 | 行为和判断 |
| --- | --- |
| CHECKING → READY | 新鲜定位／RC／参数、未解锁 POSCTL、地面稳定，锁定地面位姿 |
| PRESTREAM | 起飞请求被接受后，先在地面位姿发送约 2 s、20 Hz 目标 |
| MODE_REQUEST | 请求 OFFBOARD；这个日志是请求时刻，不是飞控实际切换时刻 |
| ARM_REQUEST | 已看到新鲜 `/mavros/state.mode=OFFBOARD`，才请求解锁；因此 OFFBOARD 在解锁之前进入 |
| RISE | 已看到 `armed=true`，参考上升约 8.578 s，峰值垂直速度 0.2 m/s |
| HOLD | 实际高度进入目标 ±6 cm 后开始保持 6 s |
| LAND_REQUEST → LANDING | 请求并确认 AUTO.LAND，随后 PX4 负责下降 |
| DONE | 同时看到落地和未解锁；不是靠倒计时假定完成 |

正常上升加保持约 14.58 s，备用 OFFBOARD 时限为 17 s，完整飞行还有降落，不能再承诺 10 s 内完成。水平偏离、定位／RC 过期、来源变化、定时器中断等仍会停止本次任务；不会自动重新解锁。

具体“从什么时候进入 OFFBOARD”需要这次日志或 bag：`MODE_REQUEST` 只给请求时刻；`ARM_REQUEST` 说明状态已经确认 OFFBOARD；首个 OFFBOARD 的 `/mavros/state` 样本给出遥测观察时刻，精度受遥测发布间隔影响。没有这些记录，不能给出真实飞控的精确切换时间。

## 已排查的问题

- `Initial state must be disarmed POSCTL with RC input`：未解锁、POSCTL、有效遥控输入至少一项不满足。读取 `/mavros/state`、`/mavros/rc/in` 找具体项；不是靠改高度或自稳解锁绕过。
- `Active alignment file changed`：会话中的对齐文件改变后，视觉转发锁止。先在落地、未解锁时恢复对齐会话；飞行时不重启定位节点。
- 等待 EV_CTRL 等参数确认：实际连续视觉转发要求 `EKF2_EV_CTRL=11`、`EKF2_HGT_REF=3`、EV_POS XYZ 为 0、QMIN 为 0；需最近参数服务确认。
- 下载失败指向 `127.0.0.1:7897`：本机代理没启动；下载命令用 `curl -q --noproxy '*'`，仍保留 TLS／HTTP 错误检查。
- 原来直接粘贴 `python3 - ... <<'PY'` 是一次性内存程序，不自动保存文件。更新命令写入 `~/Downloads/first_hover_terminal.py` 后文件才保留；旧的运行实例不会自动变成新版。

## 外参与门口绕圈

雷达相对机头名义 yaw **+45°** 已用于机体转换，名义雷达高度 10 cm 和配置内置 IMU 杆臂也参与换算。FAST_LIO 内置 IMU–LiDAR `extrinsic_R` 配置单位阵。每次测得的 `Candidate rotation quaternion` 是本次世界坐标对齐，不是独立机械安装外参标定；当前没有使用实时在线外参估计更新这些转换。

在门口标记相同位置、高度和朝向，出发静止 15 s，未解锁手持绕一圈，回到同一标记静止 30 s，再关闭录包。最小仅雷达、FAST_LIO、录包三个终端；中途不重启 FAST_LIO。完整流程见 [bag → XYZ](BAG_XYZ_2026-10-09.md)。FAST_LIO 没有回环优化，观察的是返回误差、静止稳定性、断流和点云重影，不能预设它会自动收敛回原点。
