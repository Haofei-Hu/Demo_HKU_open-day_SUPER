**The complete automatic fixed-position flight workflow has succeeded on the aircraft, including landing.** The test profile was configured for a flight-controller centre height of **1 m above the takeoff floor**, a **6-second hover hold**, and automatic landing.

The completed sequence is:

```text
Ground initialization and Position preflight
  → explicit start
  → ground setpoint prestream
  → OFFBOARD confirmation
  → automatic arming
```

This is the first successful end-to-end flight-control milestone for the deployment. It uses the standalone hover controller, rather than SUPER trajectory execution. Flight-log analysis and independent measurements are the next step for quantifying height error, drift, and repeatability; the successful functional sequence is already complete.

## Flight profile and OFFBOARD timing

The FC centre is approximately 0.085 m above the floor at rest. The 1 m profile freezes the ground pose and commands `z_ground + 0.915 m`, with fixed XY and yaw.

| Phase | Controller behavior |
| --- | --- |
| CHECKING → READY | Fresh telemetry, RC, parameters, and stable disarmed POSCTL; ground pose captured |
| PRESTREAM | Approximately 2 seconds of 20 Hz ground-position targets after the explicit start |
| MODE_REQUEST | OFFBOARD requested |
| ARM_REQUEST | Fresh FC telemetry confirms OFFBOARD before the arming request |
| RISE | Armed-state confirmation followed by a smooth ascent reference |
| HOLD | Actual local height enters target ±6 cm; the 6-second hold begins |
| LAND_REQUEST → LANDING | AUTO.LAND requested and confirmed; PX4 handles descent |
| DONE | Controller requires both on-ground and disarmed state |

OFFBOARD is entered **before arming**. Starting the process with `--execute` only enables the control path; it still waits for `/first_hover/start`. MODE_REQUEST is a request timestamp, while the first OFFBOARD state sample establishes the telemetry-observed transition time.

For this profile, the ascent reference takes approximately 8.578 seconds with a peak vertical reference speed of 0.2 m/s. Nominal ascent plus hold is approximately 14.58 seconds; the backup OFFBOARD budget is 17 seconds. Landing adds time beyond that sequence. These are controller design timings rather than measured flight durations.

## Resolved integration issues

- **Stale localization:** IMU callback backlog was isolated using input-age and queue diagnostics. The Best Effort subscription change removed the observed backlog without rewriting measurement timestamps.
- **External-vision initialization:** Vision yaw aiding enabled local heading initialization in the no-GPS deployment. XYZ/yaw aiding uses `EV_CTRL=11` and vision height reference `HGT_REF=3`.
- **Ground relay stopping after arming:** Bench-only relays were replaced by a session relay that keeps forwarding after arming while freezing source identities, geometry, and origin.
- **Alignment changes:** Geometry/source changes now latch the session relay off. Alignment updates are performed on the ground before a new session.
- **Position preflight:** Releasing Kill, with the arm switch still OFF, restored a successful POSCTL preflight. Navigation validity and Kill state are checked separately.
- **Planner preview import:** Geometry is loaded without executing another module-level ROS initialization.
- **Remote access:** AX900 driver/firmware matching and NoMachine 9.8.2 restored networked desktop operation. The recorded i915 DP-1/EDID setup supports headless use.
